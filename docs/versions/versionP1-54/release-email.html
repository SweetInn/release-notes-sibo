Release Notes - October 2026 (Version 54)

Dear Sweett Team,

In this release, the Operations Dashboard can show just the hotel you are in, and a live status of today's cleanings: what is left, what is stuck, and who is where.

Today's cleanings
See today's cleanings as they move. Delayed ones lead, with how long each has been waiting, then the ones not started, in progress, and done. Each card shows the cleaning type, the cleaner, and the company, so you can see what is left, what is stuck, and who is where. Cleaners should keep using the app, so this view stays up to date.
Filters
Filter by building or hotel. If you are working in one hotel, alerts, today's cleanings, and the top numbers show only that hotel. The full city stays in view until you narrow it.

Enhancements & Bug Fixes

  • Bug Fix Properties filterSIBO
    On Cleaning Manager, Settings, Properties, checking a property in the Properties filter updates immediately. The properties table also opens without a long wait.
  • Bug Fix Group quote hotelsSIBO
    A group quote, such as 10 adults in 10 rooms, now returns the hotels the website shows for that stay. Show only buildings/hotels limits the list to those hotels. Large apartments that sleep the whole group in one unit are no longer the only results.
