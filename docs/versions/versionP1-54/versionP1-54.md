# Version P1.54

**Released:** Oct 15, 2026

In this release, the Operations Dashboard can show just the hotel you are in, and a live status of today's cleanings: what is left, what is stuck, and who is where.

### What's New?

#### <u>Enhancements & Bug Fixes</u>

- Fixed *(SIBO)* — On Cleaning Manager, Settings, Properties, checking a property in the Properties filter updates immediately. The properties table also opens without a long wait.
- Fixed *(SIBO)* — A group quote, such as 10 adults in 10 rooms, now returns the hotels the website shows for that stay. Show only buildings/hotels limits the list to those hotels. Large apartments that sleep the whole group in one unit are no longer the only results.
