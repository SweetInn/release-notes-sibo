Release Notes - May 2026 (Version 29.2)

Dear Sweett Team,

In this release:

  • The SIBO dashboard now shows online check-in (OCI) completion rate and digital key readiness per booking, with one-click navigation to outstanding cases
  • Full Milan and Paris city guides are now available inside the Guidebooks tab in each booking, with filters to quickly find the right information without leaving SIBO. Milan and Paris teams, no more all-in-one Google Sheets 🙂
  • Airbnb guests can now modify their booking directly from the booking page, including early check-in requests, late checkout extensions before arrival, and stay extensions during the stay. The system automatically submits the alteration to Airbnb for guest approval. The same extension link is also available in the booking services view, with no Ops intervention required anymore.
  • New extension availability pre-validation tool, allowing staff to verify extension eligibility before sending an offer, avoiding situations where guests receive extension links for unavailable dates.
  • Operators are now warned when a task is scheduled outside the guest's agreed access window, helping teams better align with guest preferences.
  • In the Cleaning Tool Planner, cleaning cards now display when maintenance is scheduled at the same property, making it safer and easier to schedule cleaning tasks. In addition, the Auto-Planner ensures cleaning tasks are placed after the maintenance time slot ends when relevant.

The SIBO dashboard now shows two new readiness columns for each booking: the percentage of guests who have completed online check-in, and the percentage with a working digital key. Direct Sales & Extensions

SIBO

Direct Sales

  • Extension Availability Pre-Check
    Before sharing an extension offer with a guest, operators can verify whether the extension dates are available and the booking is eligible — directly from the services links appearing in the booking details screen in SIBO. Clear availability indicators and dates are shown, so staff can confidently offer extensions without back-and-forth.

Task Management

  • Warning When Scheduling Outside Guest's Access Window
    When an operator schedules or reschedules a maintenance task linked to a guest report, a warning now appears if the selected time falls outside the window the guest agreed to. The operator can go back and pick a different time, or proceed intentionally — avoiding visits at times the guest never approved, and ensuring the maintenance team's access code is valid when they arrive.
  • Maintenance Visibility & Auto-Scheduling in the Cleaning Planner
    When maintenance is scheduled at the same property on the same cleaning day, a visual indicator now appears on the cleaning card in the Planner. The Auto-Planner also accounts for this, automatically placing the cleaning after the maintenance time slot ends.

Reports

  • Building Filter Now Includes Property Reports
    When filtering the Reports screen by building, results now include reports filed against individual properties within that building. This gives a fuller picture of open issues across a building in one view.

Multi-Calendar

  • All Unit Rows Now Load Correctly on First View
    In the Multi-Calendar view, some single-unit property rows were not visible when the page first loaded — they only appeared after scrolling. All units now appear correctly on the initial load.

Enhancements & Bug Fixes

  • Enhancement Task Overflow Warning in OrganizerSIBO
    When reordering tasks in the Task Organizer would push one or more tasks past midnight to the following day, operators now see a clear warning before the change is applied. This prevents tasks from silently moving to an unexpected date.
  • Enhancement Smart Lock Identity Reuse Across TasksSIBO
    The system now reuses a single smart lock identity for each cleaner or maintenance worker across all their tasks at the same property, instead of creating a new one for every task. Access codes remain consistent as the workload grows, and subscription usage stays lean.
  • Bug Fix Breakfast Pricing After Booking ExtensionSIBO
    When a booking that includes a breakfast service was extended by one or more nights, the remaining balance was calculated incorrectly — the full breakfast cost was deducted for all nights instead of adding only the cost for the newly added night. The remaining amount now reflects what the guest actually owes.
  • Bug Fix Damage Protection Charged Twice in Multiple TabsWebsite/App
    If a guest had the online check-in open in more than one browser tab at the same time, they could advance through the Damage Protection step in each tab and be charged twice. The booking now allows only one Damage Protection addition per session.
  • Bug Fix Past-Date Bookings Accepted on WebsiteWebsite/App
    Guests could complete a booking on the website using past check-in or check-out dates because the system was incorrectly treating those dates as available. Bookings with past dates are now rejected at checkout.
  • Bug Fix Delivery Tasks Lost After In-Stay RelocationSIBO
    When a guest was moved to a different property mid-stay, any pending delivery tasks (such as a baby high chair or linen delivery) were incorrectly cancelled instead of being transferred to the new booking. Operations teams could miss fulfilling those requests as a result. Pending deliveries are now carried over to the relocated booking.
  • Bug Fix Expired Damage Protection Still ChargedSIBO
    When a Damage Protection task expired while a guest was partway through online check-in, completing the payment without refreshing the page still included the expired task in the total. This caused the booking to show incorrect charges or a negative remaining balance. The pricing now reflects only active, valid tasks.
  • Bug Fix Locked Task Status Could Be RevertedSIBO
    Tasks that had reached a final locked status — such as Pending Payment or Expired — could still be manually changed back to earlier statuses using the Task Table View. This risked corrupting financial records tied to those tasks. These statuses are now treated as final and cannot be manually reversed.
  • Bug Fix Lock Deletion Triggered Without an Existing CodeSIBO
    When a future booking's occupancy status was manually set to Checked Out, the system incorrectly sent a request to delete a smart lock code — even when no code had ever been created for that booking. This created a corrupt record that caused smart lock code generation to fail as the guest's arrival approached.
  • Bug Fix Duplicate Smart Lock PIN for GuestsSIBO
    In rare cases where two system events fired at the same moment for the same booking, the smart lock system created two separate access codes for the guest. This could result in one room lock not recognising the guest's PIN. The system now prevents duplicate code creation for the same booking.
  • Bug Fix Blank Channel Names in Unit PricingSIBO
    Some channels in the unit cleaning prices configuration (such as Agoda, Marriott) appeared as blank rows because their display names were missing. The list of channels shown there also differed from the one in the Property Pricing page, causing inconsistent configuration options for the same property. Both issues have been corrected.
  • Bug Fix Reassignment Didn't Update Lock AccessSIBO
    When a cleaning or maintenance task was reassigned to a different team member, the original assignee's smart lock access was not removed and the new assignee received no access at all. Each team member now receives the correct access when a task is assigned or reassigned to them.
