Release Notes - July 2026 (Version 41)

Dear Sweett Team,

This release marks a major step forward for how Sweett operations work. Maintenance dispatch is now automated. When a report comes in, SIBO checks the technician's skills and rostered shift, finds the best available match, and creates the task — all without anyone having to lift a finger. No spreadsheets, no phone calls, no manual chasing. The right person gets the job, at the right time, every time. This is the kind of smart operations platform we've been building toward, and it's here!

Also in this release: smarter cancellation handling for checkout cleaning tasks, a faster and more accessible homepage for guests, and SEO improvements across all six supported languages.

SIBO

Ops Platform

  • Automatic Maintenance Task Scheduling
    The right technician, on the right job, at the right time — without operations having to lift a finger.
    • When an eligible report is submitted, the system checks whether it qualifies for automation, then finds the best available technician by:
      • Matching their skills to the task category
      • Verifying their rostered shifts and availability
      • Factoring in the property's area and location
      • Respecting any guest timing preferences set during the stay
    • When a valid slot is found, a linked maintenance task is created and scheduled automatically — no manual steps, no chasing.
    • If scheduling is not possible, the report stays open and receives a clear system comment explaining exactly why no task was created.
    • For high-priority reports on fully booked days, the scheduler can move a lower-priority task to free up a slot, while:
      • Emergency reports are fully protected from automatic changes
      • Guest-agreed timings are fully protected from automatic changes
    • Auto-scheduled tasks appear with a dashed border in the task organiser, making them easy to distinguish from manually created tasks at a glance.
  • Cleaning & Availability — Same-Day and In-Stay Cancellation Handling
    Make the right cleaning and availability call automatically when a booking cancels at short notice.
    When a booking is cancelled on check-in day or during the stay, the system now decides automatically what to do with cleaning and availability. If the guest never arrived, cleaning is cancelled and the apartment stays open for sale. If the guest used the apartment, cleaning is scheduled for the next day and the property is blocked for that night. Occupation is determined from smart lock activity, occupancy signals, or agent confirmation — so operations no longer needs to handle these cases manually.

Enhancements & Bug Fixes

  • Enhancement Node.js 20 Runtime UpgradeSIBO
    The back-office web application now runs on Node.js 20 LTS — a supported, long-term runtime. No visible changes for users; this update improves build stability and keeps the platform's infrastructure current.
  • Bug Fix Quote Percentage DiscountSIBO
    Fixed a bug in Quote Creation where typing a multi-digit percentage discount via keyboard only registered the first digit — for example, typing "20" applied a 2% discount instead of 20%, producing a quote with an incorrect (10x lower) price reduction. The correct percentage is now applied.
  • Bug Fix Early Check-In ReadinessSIBO
    Fixed a bug where guests could be granted early check-in into an apartment that had not yet been cleaned on a same-day turnover. The system was reading a stale "clean" status left over from the previous turnover. Early check-in readiness now reflects the actual cleaning state for the arriving booking.
  • Bug Fix Chatbot Standard Check-In TimeSIBO
    Fixed a bug where the AI chatbot stated an incorrect standard check-in time when declining an early check-in request. The chatbot now reads the real check-in time from the booking and states it accurately.
  • Bug Fix WhatsApp Phone Number LabelSIBO
    Fixed a bug in the Unified Inbox where some WhatsApp conversations did not display the phone number label, despite the number being present in the system.
